# MyLauncher

A minimal Android home launcher built with Jetpack Compose.

## Features
- Pill-shaped, alphabetical list of installed apps
- Shizuku integration for hiding the Android nav bar
- Accessibility-based gesture navigation (back / home / recents)
- Long-press any app to hide, long-press blank space to unhide
- iOS-style glassy top pill, Inter font
- R8-optimized release build

## Build

```bash
./gradlew assembleRelease
